Full-Stack Developer · Ethara AI

On the Long Horizon Terminal Benchmarking (LHTB) project, testing LLM-based agents on complex, repository-level software engineering tasks.

  • Build repository-specific Docker images on Linux, set up dependencies, apply code patches and run tests in isolated environments.
  • Score model-generated fixes against ground-truth patches by comparing baseline, test-patch and fix-patch runs.
  • Turn raw test logs into structured results: passed, failed, skipped and error.
  • Track test-state transitions (f2p, s2p, n2p, p2p) to find resolved issues, regressions and failed fixes.
  • Support the evaluation harnesses and reports used to judge how reliable AI coding agents are.
